# Advanced CSS3 & Responsive Architecture

A modern, mobile-first personal portfolio demonstrating advanced CSS3 and responsive architecture.

## Features

- Semantic HTML5
- CSS Grid for two-dimensional layouts
- Flexbox for component alignment
- Mobile-first responsive media queries
- CSS variables
- Light/dark theme with localStorage
- Responsive navigation and mobile hamburger menu
- Scroll reveal animations
- Contact form frontend validation
- Responsive project cards and timeline
- Accessible labels and keyboard-friendly controls

## Folder Structure

portfolio/
- index.html
- css/style.css
- js/script.js
- images/

## Run

Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Customize

Replace placeholder contact details, project links, education information, certifications, and profile content with your own information.
